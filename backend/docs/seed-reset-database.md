# Seed Reset Database

## Commands

| Command | Effect |
| --- | --- |
| `npm run db:reset` | Deletes data from all reset collections and keeps MongoDB indexes. |
| `npm run db:reset -- --dry-run` | Prints the reset table without deleting data. |
| `npm run seed` | Upserts demo seed data without clearing runtime data. |
| `npm run seed:reset` | Resets all reset collections, then runs the full seed flow. |
| `npm run seed:reset -- --dry-run` | Prints the reset table and skips seed execution. |

## Safety

The reset script blocks targets that look like production by default. If `NODE_ENV=production` or the database name contains `prod` or `production`, the script fails unless `--force-production` is passed.
